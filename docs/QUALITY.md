# 怎样判断它是否值得继续做

“超越市场 90%”是用户的质量愿景，不是本项目当前达到的事实。它需要先定义市场集合和比较方法。Steam 好评率、下载数、自动化通过率均不能等价为质量分位。

## 阶段门槛

| 阶段 | 可核验的交付 | 退出条件 |
| --- | --- | --- |
| 可玩序章 | 六舱室、完整谜题链、三结局、存档、离线包 | 无主线阻断；明确已制作与仅设定的边界 |
| 玩家验证 | 8–12 位初次接触者，每人完成后访谈 | 至少 80% 无人工讲解掌握第一个核心动作；所有卡住位置有记录 |
| 垂直切片 | 30–60 分钟高质量内容、独特多解谜题、后果反馈 | 20–30 位目标玩家中，至少 70% 能准确复述核心谜题和自己的推理；探索动机有具体理由 |
| 商业假说 | 体验后匿名价格研究与后续自发选择 | 区分“口头说喜欢”“愿意登记测试”“真实付费”；当前尚无任何付费验证 |
| 持续体验 | 新内容和实际 D1 / D7 回访观察 | 无提醒、奖励或断签处罚条件下测量；同时记录玩完满意、不需每日回访者 |
| 比较评估 | 明确抽样框、盲测、同类竞品、评分维度 | 只有有足够覆盖度和不确定性分析时才讨论分位；便利样本不能外推全部 2D 游戏 |

上面的比例均是预设测试门槛，不是已有成绩。首轮玩家样本小，置信区间很宽，必须记录原始人数和未完成者，不能只报百分比。

## 评估维度

操作与反馈 20%；推理公平性 20%；探索欲与空间记忆 20%；叙事与角色后果 15%；视听统一性 10%；可访问性和稳定性 10%；独特性 5%。权重是内部工作工具，不是行业标准。

## 试玩提纲

先让玩家自己开始，记录何时理解移动、调查、回声、证据连线。卡住时先问“你现在想做什么、为什么”，不立刻教答案。

结束后询问：你认为发生了什么？哪条证据改变了看法？哪个选择最难？什么地方让你想关掉？如果明天没有提醒，你会因为什么再来？哪一个具体时刻让你联想到自己的生活？不要用“你是不是获得了人生启发”诱导回答。

价格研究使用可拒绝的梯度方案，在有足够内容后测试，不预设对方必须付费。所有真实玩家招募、对外联系和收费操作均另行安排；自动任务不得自行替用户联系他人。

## 当前最重要的不足

- 画面是原创程序绘制的简化场景，缺少成熟商业美术、角色动画与专业声音制作。
- 序章仅一条短案件，推理仍有预设结论；设备谜题为入门级，不能代表深度已经足够。
- 三结局的长期影响还没有可玩的后续章节承接，匿名路线现加入停航与封存代价，但目前已影响局部回收任务的载具和续航，但仍无完整跨星域章节承接；是否构成有趣且公平的权衡仍需玩家检验。
- 七段短波是有限手写内容，每日只轮换推荐，不是无限生成，也不是已证实留存机制。
- 自动化不等于人工完整体验；桌面模拟手机不等于真实 iOS / Android 验收。

## 迭代纪律

一次选择最影响体验的 1–2 项假说，先给出改变理由，再实现，再测量。保留失败记录。能正常运行之后，不能靠堆积更多测试代替改进游戏。没有独立玩家数据时，继续制作和内部审查，但不自行宣布付费、留存或市场排名达标。
