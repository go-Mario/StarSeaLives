# 分步上线计划

## 先验证网页版

先把《第十三份早餐》作为 2D 单机网页作品反复试玩。关注玩家能否理解人物处境、主动检查线索、看懂不同职业的操作，并愿意尝试另一个视角。用 `index.html` 维护模块化版本，以 `python3 tools/build.py` 生成 `dist/index.html`，该文件可作为独立离线体验包。

第一轮找少量中文玩家和英文读者做观察式试玩；之后检查桌面浏览器、iPhone Safari、安卓微信内置浏览器的触控、音频启用、前后台恢复、屏幕安全区和存档。桌面手机视口不能替代真机检查。

## 再做手机样片

网页版核心体验稳定后，挑一幕与一个休闲玩法先做 iOS 样片和微信平台样片，分别验证触控、存档、资源打包和生命周期。先基于届时官方文档核对应用类型、主体条件、内容类目和审核材料，再确定微信小程序、小游戏或 iOS 容器的具体路线。现有 HTML 页面不等于已适配平台，也不代表已经满足审核要求。

## 最后扩展为 3D 多人版本

只有当玩家反馈证明同一场景的多人物视角值得继续后，才制作一个 3D 场景试验。之后再验证 2–4 人分别掌握线索、共同推进公共事件的协作玩法，同时明确个人私密信息和公共事实的边界。账号、云存档、服务器和商业化后置。

每一阶段都以真实试玩结果决定是否进入下一步；不预先承诺上线日期，也不把移植工作描述为平台获批。
