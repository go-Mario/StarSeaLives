# 星海公约 · 人间星海 3D（多人联机样片）

归港空间站的 3D 联机版本。走进去，读取六份发光的记录终端，拼出这座站上四个人的一生。
与 2D 单机版（仓库根目录）共用同一个世界观；本目录是独立的联机样片，零第三方运行时依赖
（three.js 已本地 vendor，服务器为纯 Node 手写 WebSocket）。

## 运行

```sh
node 3d/server.js          # 默认端口 8787
# 打开 http://127.0.0.1:8787/
```

- 同一网络下的手机/电脑都可以打开这个地址联机（用服务器的局域网 IP，例如 `http://192.168.x.x:8787/`）。
- 想换端口：`PORT=9000 node 3d/server.js`。

## 操作

| 平台 | 操作 |
| --- | --- |
| 电脑 | `WASD` 移动 · `Q`/`E` 升降 · 拖动鼠标转视角 · `Shift` 快走 · `Enter` 聊天 · `E` 读记录 |
| 手机 | 左下摇杆移动 · 右半屏拖动转视角 · 右下按钮升降与读记录 |

## 已实现

- 3D 场景：归港站平台、中央舱、环、轮辐、对接舱、太阳能板、地球与星空
- 多人：加入/离开、位置实时同步（15Hz，插值平滑）、姓名牌、聊天气泡与聊天记录
- 玩法：六份双语记录终端，走近按 `E` 读取；读取状态对所有玩家广播（终端变金）
- 双语：整个界面与全部记录中英随时切换，记忆选择
- 断线自动重连（3 秒）

## 目录

```
3d/
  index.html        入口与 HUD
  css/main.css      HUD 样式（深色主题，与 2D 版一致）
  js/client.js      客户端（three.js 场景 / 输入 / 联机 / 记录终端）
  js/vendor/        three.min.js（r158，本地化，无 CDN 依赖）
  server.js         纯 Node 服务器：静态文件 + 手写 WebSocket + 房间广播
```
