# 星海公约：人间星海 / Stellar Covenant: Ordinary Lives

这是独立的 2D 单机双语叙事游戏。玩家从维修员、食堂经营者、快递员或法律援助律师的视角，经历同一星际社区的六个悬疑事件与一生选择。原《星海公约》星图／庭审游戏另在[旧作仓库](https://github.com/go-Mario/StarSeaCovenant)，本仓库只放新作，不改旧作。

## 直接游玩

打开仓库主页的 `index.html`，或用本地静态服务器：

```sh
python3 -m http.server 8766
# 打开 http://127.0.0.1:8766/
```

中文与英文可随时切换。四个人物各有单独存档；首幕调查操作各不相同：维修员校准时间、食堂经营者保留安全餐食信息、快递员按记录复原路线、法律援助律师依照家属授权安排救治。接着从找到的编号或地点检索站内记录，结果保留来源并记入手记。搜错可以重试，不扣分、不倒计时。参考作品的机制研究见[研究记录](docs/RESEARCH-2026-10-21.md)。

## 离线单文件

```sh
python3 tools/build.py
python3 tools/build.py --check
```

生成的 `dist/index.html` 可脱离服务器直接打开。页面和脚本均不依赖第三方运行时；本地存档使用独立键名，避免与旧版游戏的进度相互覆盖。

## 验证

```sh
node tools/test/lives-model.js
node tools/test/lives-browser.js
```

浏览器流程测试需先在仓库根目录启动上述静态服务器。测试覆盖中英文、四条不同职业调查、六幕分支、休闲玩法、存档恢复、离线打开和手机宽度。

## 当前阶段

这是一份持续打磨的可玩样片，不宣称已经胜过任何参照作品。先验证每条人物线都能让新玩家看懂线索、理解人物、愿意继续，再扩展更多 NPC 与共享世界后果。素材与故事为本项目原创；借鉴的是类型机制，不复制其他作品的世界观、角色或美术。
