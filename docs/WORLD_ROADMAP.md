# 一个世界，每个人的一生

## 已落地的第一卷

《第十三份早餐》从一个日常疑问开始：一位被登记为死亡的人，为什么还在订早餐？玩家先认识普通人的生活，再逐步拼合失踪、登记和站内系统之间的联系。法律是故事里的力量与代价，不要求玩家先懂法律。

目前可选四个视角：维修员林渡、食堂经营者苏弥、快递员许照、法律援助律师简。四人处在同一条时间线，各自只能看到有限材料；选择人物后，整轮始终跟随此人的知识、关系和生活抉择。每人有六幕、独立存档与个人尾声。所有人物共享同一批公共事件，但不会把多个人的全知视角拼成一轮。

第一幕的行动也按身份区分：林渡校准两只时钟；苏弥保留过敏信息并安排餐食；许照按交接记录复原配送路线；简依家属授权安排紧急救治。之后，每人都从自己看到的编号或地点进入专属站内档案系统，检索两份有来源、有证明边界的记录。搜索会记进人物手记。玩家须查看材料、完成角色行动并检索记录，才能作出推理。由此让不同职业真正改变“怎么查”，不只是替换对白。

六个共同事件从 2077 年延伸到 2127 年，涉及失踪乘客、饮水污染、迟来的来电、空间站退役与记忆留存。人物决定会改变之后能留下哪些证据、谁能得到帮助，以及最后的安置方式。故事结果关注一生中具体的关系与选择，不把普通人都写成拯救宇宙的英雄。

分支采用“共同世界结果＋个人人生尾声”：四人各六次二选一，模型覆盖 256 种路径组合，但这不等于写了 256 篇完全不同的长结局。当前有三类世界安置结果、角色尾声和可回看的选择记录。

## 辅线和语言

简的另一条主线收录六个双语法律悬疑卷宗。呈现顺序是事件、材料、选择，再提供进一步解释；它是休闲故事的另一种入口，不是推进主线的先修课。休息舱提供对接、翻牌、调频和呼吸练习；没有倒计时惩罚，也不要求玩家赢小游戏才可继续。

游戏界面、线索、剧情、选择后果、卷宗和休闲活动均支持中文与英文切换。两种语言按人物语气和句意分别编写。自动检查验证文本齐全与流程可达，但专业母语润色仍需英文读者试玩；自动化无法代替读者判断是否自然、优美、易懂。

## 下一步

1. 邀请没有法律背景的玩家试玩首幕，观察他们能否说清人物处境、谜团和下一步操作，并记录是否愿意继续。再邀请英文读者检查语气和线索表达。
2. 根据真实反馈改善首幕的声音、镜头节奏、物件反馈和线索连接；不以堆字数代替演出。
3. 将后续章节设计为约 8–12 分钟的独立调查段，每段围绕一种新交互，混合探索、线索、人物相遇和生活选择，不堆叠密码门。
4. 把站内空间扩展为少量可探索房间，让玩家通过行动发现线索和相遇；保留无障碍的文字调查入口。
5. 逐个让普通 NPC 成为可选主角。每条线都要带来独有的欲望、信息边界、交互方式、生活选择和人生余波。
6. 先在单机版尝试异步公共目标：供餐、维修、递送、援助都能推进同一站内事件。玩家体验验证后，再讨论持久社区与多人同步。
7. 先把 2D 网页单机版做稳：触控、存档、语言与平台适配都在这一个版本里打磨；账号与商业化等核心体验经玩家验证后再投入。

## 与参考作品的边界

可以研究其他作品怎样安排探索、选择、推理、重复游玩、情绪节奏和视听反馈；本项目的人物、世界观、剧情、美术和程序均应原创。研究结论与来源应记录在单独的参考文件中，不能把玩法借鉴写成设定复制。对《邺山彼处》的比较须基于实际可玩的页面和可核实体验；截图或手机模拟器首页不足以支持优劣结论。
