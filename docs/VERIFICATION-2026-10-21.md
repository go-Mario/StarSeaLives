# 版本验证记录

日期：2026-10-21。记录自动化工程检查范围，不代表外部玩家评价、英语母语编辑、真机验收或平台审核结论。

## 本轮结果

- 四个角色均有不同的第一幕互动；流程要求先查看证据、完成角色行动，再作推理。
- 四种角色各自检索一套双语站内记录；检索结果显示来源和证明范围，并随首幕选择写进人物手记。检索错误可重试，不能绕过材料和职业行动直接推理。
- 中文和英文均可完整游玩；角色文本、卷宗和结局选项通过双语成对检查。
- 六幕推理模型遍历 256 组选择组合；覆盖三类安置结果，损坏与非法存档样本受到拒绝。
- 浏览器自动化验证四个角色、六份卷宗、休息小游戏、存档恢复、导入导出、语言切换和手机视口。
- 独立 HTML 包含页面资源，可通过本地文件打开，不需要游戏运行时请求外部资源。

## 如何复验

在项目目录运行：

```sh
python3 tools/build.py
python3 tools/build.py --check
node tools/test/lives-model.js
node tools/test/lives-browser.js
```

浏览器测试需要本地静态服务器及 Playwright Chromium；环境未安装时需按本机的开发依赖配置运行。第二个浏览器流程会同时检查 `file://` 单文件版本。

## 尚待验证

自动化只能检查操作和可达性，不能判断悬疑是否吸引人、谜底是否公平或英文是否优美。还需要非法律背景玩家与英文读者试玩，并在 iPhone Safari、安卓微信内置浏览器做真机检查。
